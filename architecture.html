Data Flow

User changes a filter

FilterBar.vue writes to the useFilters composable — updates one of four reactive refs: selectedPeriod, selectedLocation, selectedCategory, selectedStatus.

View reacts and fetches

Each view watch()es the filter composable. On change, it calls the relevant api.js method (e.g. api.getOrders(filters)), passing current filter values as query params.

HTTP GET to FastAPI

Axios sends a GET request to localhost:8001/api/... with query params like ?warehouse=Tokyo&category=Sensors&month=2025-03. A filter value of all is ignored by the backend.

Backend filters in-memory data

apply_filters() narrows the pre-loaded JSON list by warehouse, category, and status. filter_by_month() handles YYYY-MM and quarter strings like Q1-2025.

Pydantic serializes the response

Filtered records are validated against Pydantic models and returned as JSON. Response shape is guaranteed — no nulls in unexpected places.

Vue updates the UI

The view stores raw data in a ref. Computed properties (totals, chart data, filtered tables) recalculate automatically. useI18n translates labels and converts currency (USD/JPY at 150) before render.

Key Constraints & Notes

Data Persistence
In-Memory Only
All mutations (purchase orders, tasks) are lost on server restart. Restart to reset to JSON defaults.
Warehouses
3 Locations
San Francisco, London, Tokyo. Hard-coded throughout backend filter logic and frontend labels.
Categories
5 Product Types
Circuit Boards, Sensors, Actuators, Controllers, Power Supplies.
Revenue Goals
Hard-coded Targets
$800K/month per warehouse, $9.6M YTD across all months. Used in Dashboard KPI cards.
Unimplemented Stubs
4 API Methods
getTasks, createTask, deleteTask, toggleTask in api.js have no backend — will return 404.
Month Filtering
Inventory Excluded
Inventory endpoints do not support month filtering — inventory has no time dimension.
